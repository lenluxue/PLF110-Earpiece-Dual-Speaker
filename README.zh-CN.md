# PLF110 听筒/底部扬声器立体声 v2.1.0

[English](README.md) | 简体中文 | [Bahasa Indonesia](README.id.md)

这是一个用于已 Root 的一加 PLF110 Android 16 固件的 KernelSU/Magisk 模块。

模块把 `AUDIO_DEVICE_OUT_SPEAKER` 和 `AUDIO_DEVICE_OUT_EARPIECE` 分配给媒体策略 5，保持听筒媒体音量随媒体音量键联动，并将 AW88265 智能功放设置为接收 I2S 右声道。听筒继续走原厂单声道路径；随包测试音用于确认当前固件是否只把左声道送到听筒，还是把左右声道折叠成单声道。这是声道分离测试，不是虚拟环绕。

在 KernelSU 或 Magisk 中安装 ZIP，然后重启。模块的操作按钮可以在无需重启的情况下开关双扬声器路由。卸载模块时会清除该路由，并恢复首次安装时保存的听筒设备音量索引。

AW88265 的通道选择使用驱动定义的 `I2SCTRL1 (0x06)` 寄存器 `CHSEL` 位（Left=`1`、Right=`2`）。模块保存原值，在启用期间持续设为右声道，并在禁用或卸载时恢复。它不修改内核、Audio HAL 或厂商增益表。

底部 AW882xx 智能功放仍通过 `aw_dev_0_volume` 独立衰减。默认值为 `96`，即 -12 dB（每步 0.125 dB，`0` 为最大音量）。监控进程会在音频路径重启后重新应用。听筒使用厂商 `Handset Volume` 控件的最大安全索引 `0`；该控件也由通话和语音消息播放共用，因此这些路径也可能变响。禁用或卸载时会恢复保存的有效混音器值。

此固件上继续禁用增益表修改，因为 MediaTek HAL 在重新加载修改后的增益表时会崩溃。模块保留原厂增益表。

低媒体音量播放 `左右声道测试.wav`：先出现的 440 Hz 是左声道，随后 880 Hz 是右声道。理想结果是低音只从听筒出、高音只从底部扬声器出。如果高音也从听筒出，说明当前 HAL 把送往听筒的左右声道折叠了，需要进一步改 HAL/策略路由。

如需只调整媒体音量，请把数字偏移量写入 `/data/adb/plf110_earpiece_dual_speaker/earpiece_offset`，然后按下模块操作按钮；默认偏移量为 160 个媒体音量步进。

如需在不重新构建模块的情况下调整左右声道响度平衡，请把 `0` 到 `720` 之间的整数写入 `/data/adb/plf110_earpiece_dual_speaker/smartpa_attenuation`。每一步只会让底部扬声器衰减 0.125 dB；例如，`24` 为 -3 dB、`32` 为 -4 dB、`40` 为 -5 dB、`48` 为 -6 dB、`64` 为 -8 dB、`80` 为 -10 dB、`96` 为 -12 dB。正在运行的监控进程会在一秒内应用新值。
