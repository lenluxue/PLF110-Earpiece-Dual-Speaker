# PLF110 听筒双扬声器 v2.0.6

[English](README.md) | 简体中文 | [Bahasa Indonesia](README.id.md)

这是一个在一加 PLF110 Android 16 固件上测试过的 KernelSU/Magisk 模块。

它会把 `AUDIO_DEVICE_OUT_SPEAKER` 和 `AUDIO_DEVICE_OUT_EARPIECE` 同时分配给当前的媒体产品策略（该 Android 16 固件上为策略 5）。听筒的媒体音量索引会保持联动，因此调节媒体音量时，两个输出会一起变化。听筒的硬件媒体音量固定在最大值（索引 160），以补偿它与底部扬声器之间剩余的主观响度差异。

在 KernelSU 或 Magisk 中安装 ZIP，然后重启。模块的操作按钮可以在无需重启的情况下开关双扬声器路由。卸载模块时会清除该路由，并恢复首次安装时保存的听筒设备音量索引。

底部 AW882xx 智能功放通过其 `aw_dev_0_volume` 混音器控件单独衰减。默认值为 `96`；AW88265 驱动每步为 0.125 dB，因此相当于衰减 12 dB（`0` 为最大音量）。如果音频 HAL 切换配置，监控进程会重新应用该值。启用模块时，听筒使用厂商 `Handset Volume` 控件的最大安全索引 `0`。该控件也由通话和语音消息播放共用，因此这些音频路径的音量也可能增大。禁用或卸载模块时，如果已保存的混音器值在硬件控件的有效范围内，模块会将其恢复。

此固件上已禁用增益表修改，因为 MediaTek HAL 在重新加载修改后的增益表时会崩溃。模块保留原厂增益表，仅通过实时设备音量和 AW882xx 控件调整平衡。

如需只调整媒体音量，请把数字偏移量写入 `/data/adb/plf110_earpiece_dual_speaker/earpiece_offset`，然后按下模块操作按钮；默认偏移量为 160 个媒体音量步进。

如需在不重新构建模块的情况下调整左右声道响度平衡，请把 `0` 到 `720` 之间的整数写入 `/data/adb/plf110_earpiece_dual_speaker/smartpa_attenuation`。每一步只会让底部扬声器衰减 0.125 dB；例如，`24` 为 -3 dB、`32` 为 -4 dB、`40` 为 -5 dB、`48` 为 -6 dB、`64` 为 -8 dB、`80` 为 -10 dB、`96` 为 -12 dB。正在运行的监控进程会在一秒内应用新值。
